# 术语表（统一语言）

代码里的命名、UI 上的文案、以及和使用者沟通时，都用这一套词。
括号内是代码标识符与常见英文说法。

## 输入管线

| 中文 | 标识符 | 含义 |
|---|---|---|
| 原始轴值 | `raw` | 硬件直出的摇杆值，各轴 `-1..1`，未经任何处理 |
| 偏转量 | `deflection` | 摇杆矢量的模长，`0..1`，`1` 表示推到底 |
| 内死区 | `inner` | 偏转量小于此值时输出为零，用于消除硬件回中漂移 |
| 外死区 | `outer` | 偏转量大于此值即视为满偏，补偿摇杆推不到底的硬件误差 |
| 死区形状 | `shape` | 轴向（方形）/ 径向（圆形）/ 混合 |
| 反死区 | `anti_deadzone` | 输出下限抬升。用于对抗**游戏内**无法关闭的死区，与内死区作用相反 |
| 响应曲线 | `ResponseCurve` | 把归一化偏转量映射为归一化输出，决定"中心精细还是边缘迅猛" |
| 曲线作用方式 | `curve_mode` | 径向（对模长作用，保持方向）/ 分轴（两轴各自作用，可分别调） |
| 满偏转速 | `yaw_speed` / `pitch_speed` | 摇杆推到底时的视角转动速度，度/秒 |
| 开镜倍率 | `ads_multiplier` | 开镜时转速的缩放系数 |
| 转向加速 | `accel_*` | 保持满偏一段时间后转速额外提升，用于兼顾微操与快速转身 |

## 辅助瞄准

| 中文 | 标识符 | 含义 |
|---|---|---|
| 辅助气泡 | `bubble` | 以准星为中心的角度半径，目标进入气泡才触发辅助，单位为度 |
| 角度误差 | `angular_offset` | 准星指向与目标中心之间的角度差，`x` 偏航 / `y` 俯仰 |
| 视野角速度 | `angular_velocity` | 目标在视野中掠过的角速度，**不含**玩家自身转动视角的贡献 |
| 减速 / 粘滞 | `slowdown` | 目标在气泡内时降低玩家转速 |
| 旋转跟枪 | `rotation` | 摄像机自动跟随目标视野角速度，"自动跟枪"感的主要来源 |
| 磁吸 | `magnetism` | 准星被持续拉向目标中心 |
| 衰减 | `falloff` | 从气泡核心到边缘，辅助强度由满衰减到零的过程 |
| 总强度 | `master_strength` | 三种机制统一的倍率，`0` 等价于完全关闭 |

## 训练

| 中文 | 标识符 | 含义 |
|---|---|---|
| 追踪 | `tracking` | 持续把准星压在横移目标上，考察摇杆中低速段控制 |
| 甩枪 | `flick` | 静止靶点间快速转移并点击，考察大幅位移的落点精度 |
| 目标切换 | `switching` | 多个移动目标之间来回切换，追踪与甩枪的结合 |
| 精度 | `precision` | 远距离小目标，考察死区外最低速段的微操 |
| 命中率 | `accuracy` | 命中数 / 射击数 |
| 在靶时间占比 | `time_on_target` | 追踪类场景的核心指标，光束停留在目标上的时间占比 |
| 过冲 | `overshoot` | 甩枪时越过目标中心的角度量，反映曲线末端是否过陡 |
